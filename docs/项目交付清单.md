## 主要入口

### 启动基础场景

```bash
bash scripts/start_docking_demo.sh
```

### 启动自动停靠

```bash
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 launch aruco_docking docking.launch.py
```

### 运行单次实验

```bash
bash scripts/run_docking_experiment.sh center 05
```

位置参数支持 `center`、`left` 和 `right`。实验编号使用两位数字。

### 生成安全测试柱

```bash
bash scripts/spawn_safety_obstacle.sh
```

### 复算实验指标

```bash
python3 scripts/analyze_runs.py data/run_*.csv --target-distance 0.35
```

### 执行交付复核

```bash
bash scripts/verify_delivery.sh
```
