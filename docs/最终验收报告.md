## 2. 验收范围

本次验收覆盖以下功能：

1. Gazebo 基础场景自动启动；
2. TurtleBot3 相机、相机参数、激光雷达和速度控制话题；
3. ArUco 标记识别、水平偏差计算和距离估计；
4. `SEARCH / TRACK / STOP` 控制状态；
5. 目标距离停车、二维码消失停车、前方障碍停车；
6. 独立 CSV 实验记录与汇总统计；
7. 正前方、左偏和右偏三组共 10 次重复实验。

## 3. 系统流程

```text
/camera/image_raw + /camera/camera_info
                  ↓
          ArUco ID 0 检测与位姿估计
                  ↓
       水平误差、标记距离、/scan 安全距离
                  ↓
           SEARCH / TRACK / STOP
                  ↓
                /cmd_vel
                  ↓
       TurtleBot3 对准、接近、停车、CSV 记录
```

控制器在水平误差超出阈值时执行原地对准；完成对准后，控制器根据距离误差计算
前进速度。图像超时、目标丢失和前方障碍会触发零速度命令。

## 6. 稳定性措施

- ROS 2 环境加载期间暂时关闭 Bash 未定义变量检查，加载完成后恢复；
- ArUco 模型使用白色留边，提高黑色边框与背景的区分度；
- 检测记忆保留最近 `0.75 s` 的有效位姿，吸收单帧漏检；
- 图像超时设置为 `1.0 s`，适配本次 WSL 仿真的相机帧间隔；
- 控制器检测到目标丢失、图像超时或近距离障碍时发布零速度；
- 实验脚本重建机器人模型，清除上一轮仿真的位置和插件状态；
- 实验脚本终止 ROS launch 父进程及控制节点子进程，并补发零速度命令；
- 已有 CSV 文件受到保留保护，新实验需要使用新的编号。
